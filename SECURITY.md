# Security Policy  

## Supported Versions  

The following table shows which versions of the AiMineMe platform are currently supported with security updates and maintenance releases.

| Version | Supported |
|---------|------------|
| 1.2.x   | ✅ |
| 1.1.x   | ✅ |
| 1.0.x   | ⚠️ Limited Support |
| < 1.0   | ❌ No Longer Supported |

> ⚙️ Active development focuses on the latest minor version (`1.2.x`).  
> Older versions may receive only critical security patches, if applicable.

---

## Reporting a Vulnerability  

We take the security of our platform and our users very seriously.  
If you believe you have found a security vulnerability, please follow the steps below:

1. **Do not publicly disclose the issue.**  
   Instead, contact us directly so that we can verify and address the problem responsibly.

2. **Send detailed information to:**  
   📧 **security@aimineme.com** *(or your real contact email if different)*  
   Include:
   - A clear description of the vulnerability  
   - Steps to reproduce (if possible)  
   - Potential impact and affected versions

3. **Response Time:**  
   - Initial confirmation within **48 hours**  
   - Full review and patch plan within **5 business days**

4. **Acknowledgment:**  
   Valid security reports will be publicly acknowledged (unless anonymity is requested).  
   We may also include your name or handle in our release notes as appreciation.

---

## Additional Recommendations  

- Always verify URLs and only use official AiMineMe resources.  
- Keep your software and dependencies updated to the latest versions.  
- Enable two-factor authentication (2FA) on your AiMineMe and GitHub accounts.
