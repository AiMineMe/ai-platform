# 🚀 AiMineMe — Professional AI-Powered Trading & Mining Platform

**AiMineMe** is a professional cryptocurrency **binary trading** and **gamified mining** platform  
built with modern technologies: **Laravel 12, Vue 3, Inertia.js, TailwindCSS, MySQL 8, PHP 8.2**.

---

## 🧩 Key Features
### 🪙 Professional Binary Trading
- Real-time UP/DOWN trading engine  
- Live crypto market data with TradingView integration  
- Payout rate configuration & trade duration control  
- Trade history, settlement, and profit/loss analytics  

### ⚡ Gamified Mining System
- Real-time mining simulation sessions  
- XP-based level system & streak multipliers  
- Daily, weekly & monthly competitions  
- Subscription-based mining fees and leaderboards  

### 💰 ICO Token Platform
- Token creation and sale management  
- Dynamic pricing and sale tracking  
- Secure purchase flow with multi-currency support  

### 💵 Financial & Wallet System
- Multi-gateway deposit & withdrawal  
- Automated fee, limit & conversion management  
- Full transaction history with admin approval system  

---

## 🔒 User Security & Verification
- Complete KYC with document, address, and selfie verification  
- Two-Factor Authentication (2FA)  
- IP, browser, and session tracking for all accounts
